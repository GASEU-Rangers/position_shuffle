# 모노폴리 위치 교란 룰렛

세 명 이상의 대상을 서로 다른 대상의 위치로 바꿉니다. 

## 링크

[바로가기](https://gaseu-rangers.github.io/position_shuffle/)

## 사용 방법
1. 이름을 입력합니다.
2. 필요 시 '항목 추가' 버튼을 통해 대상의 수를 추가합니다.
3. 룰렛 돌리기 버튼을 누릅니다.

- 중복된 값은 나오지 않습니다.
- 룰렛을 돌리면 무조건적으로 자리가 바뀌게 됩니다
- 자기 자리를 유지할 수 없습니다.

## 사용 기술
- HTML
- CSS
- JavaScript
